### GLFW的Window窗口的创建流程（The process of create GLFW window） 

上一节中，我们把`HelloTriangleApplication`这个Vulkan项目的总体框架设计并搭建完成，这让我们有了一个很好的起点来逐步构建整个项目。这一节我们将聚焦Vulkan渲染窗口的构建，有了窗口的输出界面就等同于有了输出终端，它输出的信息将决定最终渲染效果的品质。

---
#### 创建GLFW窗口

这里我们说明一下，Vulkan是一个纯图形库和API，它不参杂着任何其他的除了图形编程以外的内容，而与之相对的图形库和API，例如Directx 12和metal它们不仅拥有图形编程相关的内容，同时还具有窗口创建、数学运算以及图像处理的相关内容，虽然这些额外的内容是跟它们自身官方平台强绑定在一起的，但在构建特定平台应用程序时，这种情况会显著缩短开发时间和程序上下文的切换频率。这并不意味着Vulkan不适合构建跨平台的图形应用程序，只要为它选择一个合适的窗口库来构建窗口界面，Vulkan也将把自身的特点展现的淋漓精致。

在本项目中，我们将使用GLFW库来构建Vulkan需要的窗口界面，当然这并不是唯一的选择，如果你具有其他窗口库的开发经验，例如：GLEW、SDL库等，你完全可以尝试用你自己的经验来为Vulkan实现特定的窗口界面，这一点是十分值得鼓励的。那么话说回来这里选择GLFW库的原因是因为，它本身就是为图形库和API打造的跨平台的窗口库，最开始设计出来就是为了适配传统的图形库OpenGL，当然这里我们并无兴趣深入探讨OpenGL，但必须要说的是如果你具有OpenGL或者类似它的Direct3D的图形编程经验，你在本项目构建Vulkan应用程序时会有极大的帮助。如果你没有任何图形编程经验，那也没有关系，当你亲手写完该项目后，你会对图形编程和Vulkan这个图形库有极大的认识。

所以我们直接切入主题来创建我们需要的窗口界面。首先得在之前创建的`HelloTriangleApplication.h`的头文件中用预处理指令`#include`把GLFW库的头文件包含在该头文件中。就像这样：

**HelloTriangleApplication.h**

```cpp
#if defined(__INTELLISENSE__) || !defined(USE_CPP20_MODULES)
#include<vulkan/vulkan_raii.hpp>
#else
import vulkan_hpp;
#endif

//添加GLFW库
#define GLFW_INCLUDE_VULKAN
#include<GLFW/glfw3.h>

constexpr int SCR_WIDTH = 1200;  //窗口的宽度
constexpr int SCR_HEIGHT = 800;  //窗口的高度
```

```cpp
class HelloTriangleApplication
{
private:
    GLFWwindow* window = nullptr; //添加创建GLFW窗口的主要结构体

public:
    void run();

private:
    void initVulkan();
    void mainLoop();
    void cleanUp();
    void initWindow(); //添加初始化GLFW窗口的函数
}
```

这里我们用`#define`指令定义了一个`GLFW_INCLUDE_VULKAN`的宏，它的作用就是简化引入GLFW窗口库的操作，我们接着声明两个编译期整形常量`SCR_WIDTH`和`SCR_HEIGHT`这两个常量将决定窗口初始大小的宽度和高度。同时在`HelloTriangleApplication`类中添加`GLFWwindow`结构体的属性字段和`initWindow()`的函数方法，并将它们设置为私有属性，外界没有直接访问和调用的权力，这是符合封装性原理的。

光是这样还不够，我们在头文件中声明了属性字段和函数签名后，只代表该头文件只是该类提供给外界访问调用时的契约签名，提示外界调用的方法可以在这个类中找到，但具体如何操作的我们还并未实现，因此接下来的步骤就是在源文件中为每个函数定义实现内容。具体实现如下：

**HelloTriangleApplication.cpp**

```cpp
void HelloTriangleApplication::run()
{
    initWindow();
    initVulkan();
    mainLoop();
    cleanUp();
}
```

这里`run()`函数作为类中唯一的公有访问函数方法，他的主要目的就是将类中所有声明为私有的函数方法组织起来，供外界访问调用好让整个应用程序能够运行起来，同时无法修改类中的函数方法的具体实现。但在整个项目过程中，它仅仅只用调用这几个函数，后面我们将不会在对它进行任何修改。

**HelloTriangleApplication.cpp**

```cpp
void HelloTriangleApplication::initVulkan()
{

}
```

```cpp
void HelloTriangleAppliaction::mainLoop()
{
    while(!glfwWindowShouldClose(window))
    {
        glfwPollEvents();
    }
}
```

这两个函数方法修改较少，目前阶段我们只需要保持`initVulkan()`函数方法为空实现，但这并不意味着它不重要，相反它是我们创建Vulkan程序时，初始化Vulkan的核心函数，后面我们将展开篇幅对它进行填充讨论。而另一个`mainLoop()`函数方法，我们现阶段在其作用域内部创建一个while循环，以确保我们的窗口以及后面的所有操作都是昙花一现，转瞬即逝。在while循环的参数类表中我们调用了GLFW库的`glfwWindowShouldClose()`函数方法，它需要传入一个窗口实例的参数，判断用户已经点击了窗口界面的关闭按钮，并返回一个整形的1来退出循环主体，这里我们使用`!`取反符号来表示只要我们没点击窗口关闭按钮，循环就会一直持续下去不会停止。循环中的`glfwPollEvents()`函数方法，是GLFW库用于处理用户与窗口交互事件的主要函数，它能处理用户鼠标和键盘的输入事件并响应该事件。

**HelloTriangleApplication.cpp**

```cpp
void HelloTriangleApplication::cleanUp()
{
    glfwDestoryWindow(window);
    glfwTerminate();
}
```

`cleanUp()`函数方法中调用GLFW库的窗口销毁函数`glfwDestoryWindow()`它接收一个`GLFWwindow`结构体的窗口实例作为参数，目的就是销毁这个传入的窗口。后面的`glfwTerminate()`函数负责释放GLFW库在创建窗口的过程中分配的所有内存空间，防止出现内存泄漏的糟糕情况。

**HelloTriangleApplication.cpp**

```cpp
void HelloTriangleApplication::initWindow()
{
    glfwInit();
    if(!glfwInit()){
        std::cerr << "GLFW init failed" << std::endl;
        return;
    }
    std::clog << "GLFW init success!" << std::endl;

    glfwWindowHint(GLFW_CLIENT_API, GLFW_NO_API);
    glfwWindowHint(GLFW_RESIZABLE, GLFW_FALSE);

    window = glfwCreateWindow(SCR_WIDTH, SCR_HEIGHT, "LearnVulkan", nullptr, nullptr);
    if(!window){
        std::cerr << "Window init failed" << std::endl;
        return;
    }
    std::clog << "Window init success!" << std::endl;
}
```

最后，也是本节最重要的函数方法`initWindow()`，它是负责创建窗口函数的核心方法，它内部主要由三部分组成。首先调用GLFW库的`glfwInit()`方法，这个方法主要用于初始化GLFW库的所有内部依赖和内存分配，后面我们通过条件语句判断GLFW库是否初始化成功，并通过打印信息到终端来进一步验证。接着我们调用两次`glfwWindowHint()`方法来指定创建窗口的属性，第一次我们告诉GLFW我们的窗口不使用图形库和API，第二次告诉GLFW暂时禁用窗口尺寸的调节。最后我们调用`glfwCreateWindow()`方法创建GLFW窗口的实例，并用预先创建的`window`属性字段来接受这个窗口实例，并再一次用条件语句判断窗口是否创建成功，同时打印信息到屏幕终端。
