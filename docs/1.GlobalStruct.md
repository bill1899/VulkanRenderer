### Vulkan 项目的整体结构框架（Global struct of vulkan project）

---
#### 创建三角形类
  
  首先在Visual Studio 2022中创建一个名为`HelloTriangleApplication.h`的C++头文件以及`HelloTriangleApplication.cpp`的源文件，并在头文件中创建名为`HelloTriangleApplication`的C++类，这个类将作为我们构建并运行Vulkan三角形的整体骨架。具体代码如下展示：

**HelloTriangleApplication.h**

```cpp
#program once
#if defined(__INTELLISENSE__) || !defined(USE_CPP20_MODULES)
#include<vulkan/vulkan_raii.hpp>
#else
import vulkan_hpp;
#endif

#include<iostream>
#include<stdexcept>
#include<cstdlib>
#include<assert.h>
#include<algorithm>
#include<fstream>
#include<limits>
#include<memory>
#include<vector>

class HelloTriangleApplication
{
public:
    void run();

private:
    void initVulkan();
    void mainLoop();
    void cleanUp();
}
```

在这里我们使用`#program once`这一预处理指令防止出现任何的头文件重复包含的情况，接着定义`#if defined(__INITELLSENSE__)`和`!defined(USE_CPP20_MODULES)`这两个开关，用来控制整个项目使用传统的C++`.h`或者`.hpp`头文件还是直接使用C++20标准引入的`.ixx`或者`.cppm`的模块文件，正如上下文所展示的那样，如果我们在Visual Studio 2022中编写项目代码时，启用了`__INITELLSENSE__`和`USE_CPP20_MODULES`这两个选项，项目就会优先使用`#include<vulkan/vulkan_raii.h>`这一C++封装的头文件版本，否则就会使用`import vulkan_hpp`这一Vulkan的C++模块文件版本。

接下来就是导入这个项目所依赖的C++标准库文件，这些头文件库的作用如下：

    #include<iostream>     标准输入输出库
    #include<stdexcpect>   标准异常处理库
    #include<cstdlib>      C语言标准库，用于兼容Vulkan语法
    #include<assert.h>     标准断言判读库
    #include<algorithm>    标准数学算法库
    #include<fstream>      标准文件读写库
    #include<limits>       标准内存限制库
    #include<memory>       标准内存管理库
    #include<vector>       标准向量容器库

当完成以上所有的C++标准库引入项目中后，我们便开始创建项目的主要核心`HelloTriangleApplication`类和名为`main.cpp`的C++源文件，前者负责组织并归纳代码让代码看起来不是那么混乱和糟糕，后者提供程序运行入口让我们辛苦写的代码不是一文不值，而是切实可用的计算机应用程序。

#### 主函数文件

当然`main.cpp`文件的内容在该文档的当前阶段也并不算太复杂，甚至可以说是很基础，当前阶段我们在`main.cpp`文件编写的内容和用C++写出第一个**hello world**!**极其相似，在某种程度上还要简单一些。如下所示：

**main.cpp**

```cpp
#include"HelloTriangleApplication.h"

int main()
{
    HelloTriangleApplication app;
    try {
        app.run();
    }
    catch(const std::exception& e) {
        std::cerr << e.what() << std::endl;
        return EXIT_FAILURE;
    }

    return EXIT_SUCCESS;
}
```

上面整段代码中，我们先创建`HelloTriangleApplication`类的实例，在利用C++提供的异常处理方法`try`和`catch`关键字，确保程序在运行故障或崩溃时能够优雅的提示错误信息并输出到控制台，而不是不提供错误信息的直接终止，这种操作在开发任何应用程序时都应该坚持，因为它会大幅减少后期维护程序的成本。
