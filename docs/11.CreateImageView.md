## Vulkan图像视图的创建流程（The process of Vulkan iamgeView）

在上一节中，我们谈论了如何完整的创建Vulkan图像视图的流程，它让我们的GLFW窗口得以切换更新Vulkan渲染出来的最新图像，而不至于一直卡在第一帧就不动了。那么接下来呢，我们将深入探讨Vulkan图像视图的创建流程，这个同样是Vulkan的关键部件，如果说渲染界面定义了Vulkan图像渲染工具的画板，那交换链就是定义了Vulkan如何灵活高效的切换已经渲染好的图像帧时，交换链相当于画布，本章节的图像视图就是这个画布自身的属性，比如画布的材质、背景色等，如果你能理解这个知识那么本章节的内容对你来说会容易很多，因为图像视图本质就是在决定画布是宣纸还是素面纸、背景色是白色还是黑色。

### 图像视图的创建流程
#### 1.创建头文件契约

按照以往的老规矩，我们在创建任何Vulkan结构体之前都必须先在头文件中添加相应的属性字段作为类成员属性来保存代码块中位于栈内存中的局部变量。这一章节我们也不例外，首先还是到头文件中声明契约，我想说的是这种做法是在编程当中很好的习惯，尤其是C/C++的相关项目。具体的创建内容如下展示：

**HelloTriangleApplication.h**

```cpp
class HelloTriangleApplication
{
private:
    GLFWwindow*                        window          = nullptr;     //窗口属性
    vk::raii::Context                  context;                       //Vulkan上下文
    vk::raii::Instance                 instance        = nullptr;     //Vulkan实例
    vk::raii::DebugUtilsMessengerEXT   debugMessager   = nullptr;     //Vulkan验证层
    vk::raii::PhysicalDevice           physicalDevice  = nullptr;     //物理设备
```

#### 2.实现图像传输的步骤
##### 1.第一步：断言扩容

**HelloTriangleApplication.cpp**

```cpp
void HelloTriangleApplication::CreateImageView()
{
    //断言检查
    assert(swapChainImageView.empty() && "Image view swapChain not be empty!");
    //预先设置容器容量，避免频繁扩容导致性能降低
    swapChainImageView.reserve(swapChainImages.size());
}
```

在以上代码中，交换链图像视图只是用来观察交换链图像的窗口（它类似于C++中`std::stringView`和`std::string`的关系），这里先对图象视图容器进行空容器判断，如果容器为空就立即终止程序并输出自定义的日志信息。接着将图像视图容器的大小预先设定为当前图像容器的大小，这样就避免了容器动态更新大小时造成的性能损耗。

---

##### 2.第二步：Vulkan图像视图结构体

在创建图像视图之前，我们首先先来了解相关结构体的内部属性都有哪些，这对于掌握Vulkan来说是最为关键且有效率的一步。Vulkan中创建图像视图的结构体是`vk::ImageViewCreateInfo`，我们来看看它的具体属性吧。

**vk::ImageViewCreateInfo**

```cpp
struct ImageViewCreateInfo 
{
    static const bool allowDuplicate = false;
    static Structure structure = Structure::eImageViewCreateInfo;
    
    vk::ImageViewCreateFlags  flags_            = {};
    vk::Image                 image_            = {};
    vk::ImageViewType         viewType_         = {};
    vk::Format                format_           = {};
    vk::ComponentMapping      components_       = {};
    vk::ImageSubresourceRange subresourceRange_ = {};
    const void*               pNext_            = {};
}
```

- `flags_`：图像视图的创建标志，目前 Vulkan 规范中没有定义任何可用的标志，一般设置为 0 或空。
- `image_`：要为其创建视图的原始图像对象，是图像视图的 “数据源”。
- `viewType_`：指定图像视图的类型，决定了 GPU 如何解释图像数据，例如：
  - `vk::ImageViewCreateInfo::e2D`：将图像视为 2D 纹理
  - `vk::ImageViewCreateInfo::e3D`：将图像视为 3D 纹理
  - `vk::ImageViewCreateInfo::eCube`：将图像视为立方体贴图
  - `vk::ImageViewCreateInfo::e1D`：将图像视为 1D 纹理
- `Format_`：图像数据的格式，定义了每个像素的存储方式，例如 `VK_FORMAT_R8G8B8A8_UNORM` 表示 8 位 RGBA 无符号归一化格式。
- `compnents_`：颜色分量的重映射规则，可以将图像的 RGBA 通道重新映射到视图的输出通道，例如将红色通道映射到 alpha 通道，常用于纹理格式转换。
- `subresourceRange_`：指定图像视图要包含的子资源范围，包括：
  - `aspectMask`：要使用的图像方面（颜色、深度、模板等）
  - `baseMipLevel / levelCount`：要包含的 mipmap 层级范围
  - `baseArrayLayer / layerCount`：要包含的数组层范围
- `pNext_`：指向扩展结构的指针，用于传递 Vulkan 扩展所需的额外数据，没有扩展时设为 nullptr

##### 3.第三步：为每个图像创建图像视图



**HelloTriangleApplication.cpp**

```cpp
void HelloTriangleApplication::CreateImageView()
{
    //上面代码保持不变

    for(auto& image : swapChainImages) {
        vk::ImageViewCreateInfo imageViewCreateInfo = {
            imageViewCreateInfo.flags = {},
            imageViewCreateInfo.image = image,
            imageViewCreateInfo.viewType = vk::ImageViewType::e2D,
            imageViewCreateInfo.format = swapChainSurfaceFormat.format,
            imageViewCreateInfo.components = {
                vk::ComponentSwizzle::eR,
                vk::ComponentSwizzle::eG,
                vk::ComponentSwizzle::eB,
                vk::ComponentSwizzle::eA
            },
            imageViewCreateInfo.subresourceRange = {
                vk::ImageAspectFlagBits::eColor,
                0,
                1,
                0,
                1
            }
        };
    }
}
```
