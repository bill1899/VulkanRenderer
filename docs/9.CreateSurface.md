## Vulkan渲染界面的创建流程（The process of Vulkan Surface）

上一节中，我们了解了Vulkan队列和队列家族创建流程。这一节中进一步了解Vulkan渲染界面的创建，Vulkan的渲染结果需要通过渲染界面**Surface**输出到GLFW窗口呈现出结果，因此它需要和之前的GLFW库窗口进行适配，这一章节篇幅会稍短，原因在于Vulkan的渲染界面创建少了之前其他操作的查询环节，可以直接创建渲染界面的结构体并进行配置。那么接下就了解一下如何创建Vulkan渲染界面的过程吧。

---

### 渲染界面的创建流程
#### 1.创建头文件契约

在创建任何Vulkan设备之前，我们都需要在头文件中声明相关的契约属性，这是现代C++的最佳实现方案。因此，按照之前的步骤到头文件私有属性字段中创建Vulkan渲染界面的属性实例对象。具体创建过程如下：

**HelloTriangleApplication.h**

```cpp
class HelloTriangleApplication
{
private:
    GLFWwindow*                        window          = nullptr;     //窗口属性
    vk::raii::Context                  context;                       //Vulkan上下文
    vk::raii::Instance                 instance        = nullptr;     //Vulkan实例
    vk::raii::DebugUtilsMessengerEXT   debugMessager   = nullptr;     //Vulkan验证层
    vk::raii::PhysicalDevice           physicalDevice  = nullptr;     //物理设备
    vk::raii::Device                   device          = nullptr;     //逻辑设备
    uint32_t                           queueIndex      = ~0;
    vk::raii::Queue                    graphicsQueue   = nullptr;     //图形队列
    vk::raii::SurfaceKHR               surface         = nullptr;     //Vulkan 渲染界面（新添加）
}
```

---

#### 2. 创建并配置Vulkan渲染界面

在正式创建Vulkan渲染界面之前，按照常规我们首先的了解Vulkan渲染界面窗口的结构体需要显示配置哪些属性，所以我们需要了解渲染界面结构体的内部契约签名的结构。那么Vulkan渲染界面的结构体展示如下：

**HelloTriangleApplication.cpp**

```cpp
void HelloTriangleApplication::CreateSurface()
{
    VKSurfaceKHR _surface;
    if(glfwCreateWindowSurface(static_cast<VKInstance>(*instance), window, nullptr, &_surface) != VK_SUCCESS){
        throw std::runtime_error("failed to create window surface");
    }

    surface = vk::raii::SurfaceKHR(instance, _surface);
    std::clog << "Vulkan surface create success!" << std::endl;
}
```

这段代码的核心目的是基于GLFW窗口和已创建的Vulkan实例，先通过C风格的Vulkan API创建窗口表面（Surface），再将其封装成C++风格的 Vulkan RAII包装对象，并做简单的有效性检查。详细解释如下：

###### 创建渲染界面实例对象
    VKSurfaceKHR _surface;
    if(glfwCreateWindowSurface(static_cast<VKInstance>(*instance), window, nullptr, &_surface) != VK_SUCCESS){
        throw std::runtime_error("failed to create window surface");
    }

- `VKSurfaceKHR _surface`：声明一个 C 风格的 Vulkan 表面句柄变量 _surface，VKSurfaceKHR 是 Vulkan 原生 API 中表示窗口表面的句柄类型，本质是一个不透明的指针 / 标识符。
- `glfwCreateWindowSurface()`：GLFW 库提供的封装函数，用于简化 Vulkan 窗口表面的创建（不同操作系统创建表面的逻辑不同，GLFW 帮我们屏蔽了平台差异）。
- 参数解释：
  - `static_cast<VKInstance>(*instance)`：将 C++ RAII 封装的 Vulkan 实例对象解引用后，强转为 C 风格的 VKInstance 句柄（因为 GLFW 接口只认原生 C 句柄）
  - `window`：GLFW 创建的窗口对象（GLFWwindow* 类型），表示要绑定渲染的窗口
  - `nullptr`：可选的分配器回调（一般用默认的，传空）
  - `&_surface`：输出参数，创建成功后会把生成的表面句柄写入这个变量
- 整体逻辑：如果创建表面的返回值不是 VK_SUCCESS（Vulkan 成功标识），则抛出运行时异常，终止程序并提示 “创建窗口表面失败”。


###### 存储渲染界面的临时实例对象

    surface = vk::raii::SurfaceKHR(instance, _surface);
    std::clog << "Vulkan surface create success!" << std::endl;

- `surface = vk::raii::SurfaceKHR(instance, _surface)`：将 C 风格的 VKSurfaceKHR 句柄封装成 Vulkan-Hpp 库提供的 RAII 风格 SurfaceKHR 对象 surface，减少C风格的手动指针管理，避免内存泄漏。
- `std::clog << "Vulkan surface create success!" << std::endl`：表面创建成功后，输出日志提示 Vulkan 表面创建成功。
